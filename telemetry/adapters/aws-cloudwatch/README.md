# AWS CloudWatch

Auth: AWS CLI / profile. Never print secrets.

Breakage: Logs Insights, metrics, X-Ray if wired. No session replay. No flags. No product funnels.
Product: latency and error rate on the API or job behind a feature. Say funnels are unavailable. Do not invent step-by-step drop-off from logs unless the events are actually there.

Bring the log group, the query, and the request id.
